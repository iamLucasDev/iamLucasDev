## 🚀 Projeto em destaque

### Sistema de Almoxarifado

Aplicação de gerenciamento de materiais, depósitos, estoque e movimentações de entrada e saída.

**Tecnologias:** Java, Spring Boot, Spring Data JPA, Hibernate, SQL, H2 Database, React e JavaScript.

- Desenvolvimento de APIs REST.
- Modelagem de dados e relacionamentos entre entidades.
- Regras de negócio para controle de estoque.
- Integração entre front-end e back-end.
